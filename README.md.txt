# Blood Bank Management System

## Project Description
This project is developed using MSSQL to manage blood donors, blood inventory, hospitals, and blood requests. The system helps in maintaining donor records, tracking blood stock, and managing blood requests efficiently.

---

## Features
- Donor Management
- Blood Inventory Management
- Hospital Blood Requests
- Blood Donation Tracking
- Views and Functions
- Triggers and Transactions

---

## Database Tables
- Donor
- Hospital
- BloodInventory
- BloodDonation
- BloodRequest

---

## SQL Concepts Used
- DDL Commands
- DML Commands
- Joins
- Subqueries
- Views
- Functions
- Triggers
- TCL Commands
- DCL Commands
- Indexes

---

## How To Run
1. Create Database
2. Run ddl_scripts.sql
3. Run dml_scripts.sql
4. Run queries.sql
5. Run views.sql
6. Run functions.sql
7. Run triggers.sql
